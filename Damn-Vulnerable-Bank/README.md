# Damn Vulnerable Bank (DVB)

## Overview
Damn Vulnerable Bank (DVB) is an intentionally vulnerable Android application designed for practicing mobile application security testing.

## Objectives
- Apply the OWASP Mobile Application Security Testing Guide (MASTG).
- Practice static and dynamic analysis.
- Investigate Android security vulnerabilities.
- Document findings, evidence, and remediation.

## Testing Environment
- Android
- Mobexler
- JADX
- APKTool
- Burp Suite
- Frida

## Methodology
- Environment Setup
- Static Analysis
- Dynamic Analysis
- Vulnerability Assessment
- Findings Documentation
