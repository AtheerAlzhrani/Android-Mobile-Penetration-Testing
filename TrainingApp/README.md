# TrainingApp – Android Security Assessment

## Overview
A practical Android application security testing project focused on identifying and analyzing mobile application vulnerabilities through static and dynamic analysis.

## Tools
- Mobexler
- ADB
- JADX
- APKTool
- Burp Suite
- Frida
- MobSF

## Testing Methodology
- Environment Setup
- Static Analysis
- Dynamic Analysis
- Network Security Testing
- Authentication & Authorization Testing
- Vulnerability Assessment
